# AGENTS.md

This repository is a source-first UI/UX knowledge catalog.

## Required behavior
- Read `SKILL.md` and `data/catalog.json` before recommending external UI resources.
- Never infer that an unknown license permits copying.
- Prefer semantic HTML, progressive enhancement, accessibility, responsive behavior, and static/local-first architecture.
- Keep GitHub Pages repository-subpath compatibility.
- When adding a resource, record canonical upstream URL, license status, tags, category, and review note.
- Do not add remote executable scripts or secrets.
- For UI changes validate keyboard focus, 320px mobile layout, empty/error states, dark/light themes, and reduced motion.
