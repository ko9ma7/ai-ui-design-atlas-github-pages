단순 링크 모음이 아니라 각 GitHub 프로젝트의 About 정보, README 핵심 내용, 대표 이미지·스크린샷, 라이선스, 태그, 사용 맥락을 함께 보여주고, 필요한 자료를 Codex·Claude Code 등 코딩 에이전트의 작업 컨텍스트로 빠르게 연결하는 것을 목표로 합니다.
